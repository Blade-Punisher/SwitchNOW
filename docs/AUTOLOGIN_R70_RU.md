# Все автологины R70

Настройка — в карточке соответствующей игры. Профили NTE, Genshin Impact, Honkai: Star Rail, Wuthering Waves, Zenless Zone Zero и Epic используют **единый запуск**:

**Удержать Minus + R3 0,3 секунды → после подсказки нажать X.**

Можно отпустить префикс и выбрать X в течение пяти секунд либо продолжать удерживать. Старое L+X отключено. B отменяет выполняемый сценарий. Перед входом закройте экранную клавиатуру и откройте нужную форму.

- Для NTE используйте прежний первый экран входа по почте.
- Для Genshin, Honkai, Wuthering Waves и ZZZ откройте показанную ранее форму почты/логина и пароля.
- Для Epic выберите магазин Epic в карточке и откройте первый экран с email. Fortnite исключён. Если доступны аккаунт игры и Epic, после X выберите нужный профиль кнопками вверх/вниз и A. B закроет выбор.

Файлы создаются автоматически после сохранения данных:

| Профиль | Файл на SD |
|---|---|
| NTE | switch/SwitchNOW/nte/nte.txt |
| Genshin | switch/SwitchNOW/Genshin/Genshin.txt |
| Honkai | switch/SwitchNOW/Honkai/Honkai.txt |
| Wuthering Waves | switch/SwitchNOW/wuwa/wuwa.txt |
| ZZZ | switch/SwitchNOW/zzz/zzz.txt |
| Epic, общий для игр Epic | switch/SwitchNOW/Epic/Epic.txt |

Существующие файлы переносить не нужно. Формат остаётся `email=...` и `password=...` на отдельных строках. Для Genshin, Honkai и ZZZ возможен логин без @. Поддерживаются печатные ASCII-символы. Данные хранятся открытым текстом на вашей SD; удалить можно через меню автовхода. Сборка содержит только README и не заменяет файлы с паролями.

Настройка Epic отдельно предупреждает о 2FA: для входа без ручного кода нужна отключённая 2FA, иначе проверку проходят вручную. Подробнее — в EPIC_AUTOLOGIN_RU.md. Сценарии не обходят капчу и другие проверки. Сообщение об отправке не является подтверждением успешной авторизации.
