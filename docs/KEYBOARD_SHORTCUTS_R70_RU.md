# Команды во время стрима — R70

Зажмите **Minus + R3** примерно на **0,3 секунды** и дождитесь подсказки. R3 — нажатие правого стика. Затем нажмите одну кнопку:

| Кнопка | Действие |
|---|---|
| ZL | Esc |
| L | Tab |
| R | Alt+Tab |
| ZR | Windows |
| Y | Открыть клавиатуру |
| X | Автологин, если есть подходящий профиль |
| B | Отменить выбор команды |

После подсказки можно отпустить Minus + R3. Тогда на выбор отводится 5 секунд, и режим закрывается после одной команды. Если продолжать удерживать префикс, можно выбирать команды новыми нажатиями. Заранее зажатая кнопка не вызывает отложенного срабатывания. При отмене нужно отпустить префикс перед новой активацией.

Внизу экрана видны доступные кнопки и обратный отсчёт. Пока открыт режим команд, игровые кнопки и сенсорная мышь остаются локальными. После выбора они удерживаются локально до отпускания использованной кнопки. Для возврата в игру без команды нажмите B. Одновременные команды игнорируются. Меню Minus+Plus имеет приоритет; сочетание завершения стрима не перехватывает выбор.

Все автологины теперь запускаются через X в этом режиме. Старый L+X отключён. В NTE используйте первый экран почтового входа; в четырёх играх — их форму логина/пароля; в Epic — первый экран email. Если доступны аккаунт игры и Epic, выберите нужный тип аккаунта вверх/вниз и подтвердите новым нажатием A. B отменяет выбор и уже выполняемый автоввод. Подробности — в AUTOLOGIN_RU.md и EPIC_AUTOLOGIN_RU.md.

Сами Esc/Tab/Win удерживаются минимум 60 мс, Alt+Tab имеет отдельные события Alt и Tab. Отклонённая отправка не пропускает отпускание клавиши; при переподключении сохраняется необходимое освобождение модификаторов. Обслуживание соединения продолжается при локальном вводе. Реакция облачного окружения на Windows/Alt+Tab зависит от сервера; нативная сборка не заменяет проверку игры на Switch.
